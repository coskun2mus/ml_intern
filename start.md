1. Terminal: Backend'i Başlat
Backend, ajanın beynini ve API hizmetini sağlar.

powershell
cd "d:\JS LESSONS\101.WEB.SCRAPT\ml-intern"
uv run python backend/main.py
(Bu komut port 7860 üzerinde çalışacaktır.)

2. Terminal: Frontend'i Başlat
Frontend, senin ajanla konuştuğun web arayüzünü sağlar.

powershell
cd "d:\JS LESSONS\101.WEB.SCRAPT\ml-intern\frontend"
pnpm dev
(Bu komut port 3756 üzerinde çalışacaktır.)

3. Kullanıma Başla
İki terminal de çalıştıktan sonra tarayıcını aç ve şu adrese git: 👉 http://localhost:3756
